# Sensor-Based Fertilizer Dispensing System for Precision Agriculture

## Project Description
This project focuses on developing an automated system that uses soil sensors (moisture, NPK, and pH) to monitor real-time soil nutrient levels and dispense the appropriate quantity of fertilizer accordingly. A microcontroller processes sensor data and controls a motorized dispensing mechanism, ensuring fertilizer is applied only where and when needed. This reduces manual intervention, minimizes fertilizer wastage, and improves crop yield through precision agriculture practices.

The mechanical assembly is modeled and simulated in Fusion 360 to validate the design, motion, and structural feasibility of the dispensing unit before fabrication.

## My Role

I also carry out motion and stress simulations within Fusion 360 to validate the mechanical design and structural feasibility before fabrication.

## Technologies/Tools Used

## Features
- Real-time soil parameter monitoring (moisture, NPK, pH)
- Automated, sensor-triggered fertilizer dispensing
- Reduced fertilizer wastage and manual labor
- CAD-validated mechanical design for reliability
